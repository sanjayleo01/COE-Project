# Architecture

Return text + product attributes + listing content + customer action + inspection findings
→ evidence normalisation
→ source-aware rules + TF-IDF semantic similarity
→ confidence fusion
→ root-cause label + evidence bundle
→ high-priority gate / manual review
→ product-team validation
→ taxonomy/threshold tuning.

The baseline is keyword-only. The upgraded path uses semantic similarity as a supporting signal while explicit inspection, measurement, customer-action and listing evidence receive stronger weights.
